## 使用说明

### 目录约定

| 目录 | 用途 |
| --- | --- |
| `content/` | 全部笔记源文件，按主题分文件夹 |
| `content/attachments/` | 图片等附件资源 |
| `content/templates/` | 写作模板，不参与发布 |
| `content/private/` | 私密内容，已在配置中排除 |

### 写作约定

- 数学与化学式一律用 LaTeX：`$K_{sp}$`、`$\mathrm{Ag_2CO_3}$`
- 表格用于同类数据横向对照，便于快速比对
- 笔记之间用 `[[双链]]` 互链，站点会自动生成反向链接与关系图谱

### 同步方式

```bash
./sync.sh          # 提交并推送全部改动
./sync.sh "说明"   # 带自定义提交信息
```

远端仓库：[yusufyian/chemistry-notes](https://github.com/yusufyian/chemistry-notes)

### 同步脚本已验证

`./sync.sh` 在 git 传输层被阻断时会自动切换到 API 通道。
