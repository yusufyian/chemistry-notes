# 碱金属与碱土金属

## 一、碱金属（Li、Na、K、Rb、Cs）

### 物理性质递变

| 性质 | 递变方向（Li → Cs） |
| --- | --- |
| 熔点 | 降低（Li 180.5 ℃ → Cs 28.4 ℃） |
| 沸点 | 降低 |
| 密度 | 降低，但 K 为例外（0.86 g/cm³，比水轻） |
| 硬度 | 降低 |

**原因**：原子半径增大，金属键强度减弱。

### 化学性质递变

| 性质 | 递变方向（Li → Cs） |
| --- | --- |
| 与水反应剧烈程度 | 增强（Li 缓慢 → Cs 爆炸） |
| 金属性 | 增强 |
| 还原性 | 增强 |
| 第一电离能 | 降低 |

与水反应通式：

$$
\mathrm{2M + 2H_2O \rightarrow 2MOH + H_2 \uparrow}
$$

### 焰色反应

| 元素 | 焰色 |
| --- | --- |
| Li | 红色（洋红） |
| Na | 黄色 |
| K | 紫色（透过蓝色钴玻璃观察） |
| Ca | 砖红色 |
| Ba | 黄绿色 |

> [!note] 为什么钾要透过蓝色钴玻璃
> 钠的黄色极强，会掩盖钾的紫色。蓝色钴玻璃滤去黄光，使钾的紫色显现。

### 重要化合物

| 化合物 | 性质 | 用途 |
| --- | --- | --- |
| Na₂O₂ | 淡黄色固体，与 CO₂ 反应放出 O₂ | 潜水艇供氧 |
| NaHCO₃ | 受热分解，受热或遇酸放出 CO₂ | 焙粉 |
| Na₂CO₃ | 强碱，溶液因水解呈碱性 | 玻璃、造纸 |
| NaCl | 稳定性强 | 氯碱工业、调味 |

过氧化钠与二氧化碳反应（潜水艇供氧原理）：

$$
\mathrm{2Na_2O_2 + 2CO_2 \rightarrow 2Na_2CO_3 + O_2}
$$

## 二、碱土金属（Be、Mg、Ca、Sr、Ba）

### 递变规律

与碱金属类似：原子半径增大 → 金属性增强 → 与水反应更剧烈。

与水的反应却呈现不同规律：

| 金属 | 与水反应 | 现象 |
| --- | --- | --- |
| Be | 不反应 | 致密氧化膜保护 |
| Mg | 冷水缓慢，热水剧烈 | 生成 Mg(OH)₂ |
| Ca | 冷水即反应 | 生成 Ca(OH)₂ |
| Sr、Ba | 冷水剧烈 | 反应更快 |

### 重要性质

**钙的焰色为砖红色**，与钠的黄色需区分。

**烧石膏**：加热 $\mathrm{CaSO_4 \cdot 2H_2O}$ 失去结晶水得到 $\mathrm{CaSO_4 \cdot 0.5H_2O}$，
再遇水硬化：

$$
\mathrm{CaSO_4 \cdot 0.5H_2O + 1.5H_2O \rightarrow CaSO_4 \cdot 2H_2O}
$$

这一可逆过程使石膏制品可塑形。

### 难溶盐与沉淀

碱土金属的碳酸盐（除 Be 外）均难溶，可用于鉴别 $\mathrm{Ca^{2+}}$、$\mathrm{Ba^{2+}}$：

| 试剂 | 现象 | 依据 |
| --- | --- | --- |
| 草酸铵 | 白色沉淀 | $\mathrm{CaC_2O_4}$ 难溶，见 [[常见难溶电解质的溶度积常数]] |
| 铬酸钾 | 黄色沉淀 | $\mathrm{BaCrO_4}$ 难溶 |
| 硫酸钠 | 白色沉淀 | $\mathrm{BaSO_4}$ 难溶 |

## 三、对比速查

| 对比项 | 碱金属 | 碱土金属 |
| --- | --- | --- |
| 价电子 | $ns^1$ | $ns^2$ |
| 常见离子 | $\mathrm{M^+}$ | $\mathrm{M^{2+}}$ |
| 氢氧化物碱性 | 强碱 | 碱性由上到下增强，Be(OH)₂ 为两性 |
| 碳酸盐热稳定性 | 稳定 | 从上到下递减 |
| 焰色 | Li 红 / Na 黄 / K 紫 | Ca 砖红 / Ba 黄绿 |
